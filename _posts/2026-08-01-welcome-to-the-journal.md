This is the first entry in the journal. From here on, new updates, project notes, and random thoughts go here instead of getting buried in the project pages.

To add a new entry: create a new file in `_posts/` named `YYYY-MM-DD-a-short-title.md`, add the front matter block at the top (like this one), and write in normal markdown below it. GitHub Pages builds it automatically on push — no extra steps.
